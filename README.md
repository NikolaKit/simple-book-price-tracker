# Python Book Price Tracker

A web scraping script built with Python that scrapes titles and prices from Books to Scrape and filters them based on user budget.

## Tech Stack
- Python 3
- BeautifulSoup4
- Requests

## How to Run
1. Clone the repository:
   git clone https://github.com/TVOJ_USERNAME/simple-book-price-tracker.git
   cd simple-book-price-tracker

2. Install dependencies:
   pip install -r requirements.txt

3. Run the script:
   python tracker.py
